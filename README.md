# ТРЛ — прототип сайта

Статический дизайн-прототип для ООО «Технические решения логистики».
HTML, CSS, JavaScript и Three.js. Публикация через GitHub Pages из корня ветки main.

Добавлены два блока с обработанными фотографиями склада, отдельными HTML-текстами и анимацией маршрута. Исходные снимки предоставлены заказчиком, изображения прошли ИИ-ретушь; мелкие детали могли измениться. Контакты пока не заполнены. Прайс обновлён по коммерческому предложению от 01.04.2026, подтверждённому заказчиком как актуальное. Все 34 позиции сверены с исходным документом.
